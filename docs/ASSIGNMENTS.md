# Voice assignments

Open **Voices > Assignments**, enter a username and choose a voice. Matching
ignores capitalization and applies across platforms. Only special assignments
appear here; viewers using the default voice are not added automatically.

Use **Edit** to change an assignment, **Reset** to return to the default voice,
or **Delete** to remove it. These actions do not delete speech history.

**Roles & rules** lets you choose defaults for broadcasters, moderators, VIPs,
subscribers and custom groups. The Streamer.Bot import forwards the information
available from each event. An explicitly chosen voice overrides these defaults.

Chat voice tags can use every enabled voice by default. Access options are under
**Settings > Speech input**.

Optional sentence splitting is also in Speech input. It creates separate clips
and queue entries, preserving playback order. It can add pauses and provider
requests, so it is off by default. SSML stays intact; each input supports up to
50 resulting clips.
