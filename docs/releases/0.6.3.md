# YapLoq 0.6.3

- **Clearer Save feedback.** Save messages briefly flash and fade. Click a
  message to read the full details or copy them. The last result stays available
  in Save's right-click menu.
- **Edit existing actions.** Older migrated actions can change triggers without
  being recreated.
- **One Queue trigger menu.** Queue events are grouped together, without
  duplicate legacy choices.
- **Additions to an active queue.** The new **Message added to active queue**
  trigger runs once when an input joins an existing queue, not when a new queue
  starts. Splitting that input into voices or sentences does not repeat it.

## Update

Use the download icon beside the version number, or download
**YapLoq-Windows-x64-update.zip** and extract the complete folder.

Windows 10/11, 64-bit. Keep `_internal` beside `YapLoq.exe`. No Python installation
is required. This build is unsigned, so Windows may show a SmartScreen warning.
