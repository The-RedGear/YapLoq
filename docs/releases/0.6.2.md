# YapLoq 0.6.2

- **Save feedback beside the button.** A brief message confirms a successful
  save or explains why it failed. Unsaved changes keep the button highlighted.
- **Fixed action picker text.** Cached Streamer.Bot actions no longer appear
  combined in one field.
- **Renamed and deleted actions.** Renames follow the action's ID. Deleted
  actions show a warning and can be replaced before saving.
- **Fixed exit protection at startup.** The Save-and-exit guard now loads in
  the correct order.

## Update

Use the download icon beside the version number, or download
**YapLoq-Windows-x64-update.zip** and extract the complete folder.

Windows 10/11, 64-bit. Keep `_internal` beside `YapLoq.exe`. No Python installation
is required. This build is unsigned, so Windows may show a SmartScreen warning.
