# YapLoq 0.6.5

- **Dashboard message groups.** Expand split messages to see voices and sounds in playback order, then replay the whole message from its header. Groups keep the first voice's icon and color, just like the Queue page.
- **More reliable saving.** Hidden sound-editor edits no longer block unrelated changes or prevent the app from closing. Invalid values stay available to correct, with errors that identify the affected section.
- **Clear save notices.** Fixed garbled punctuation in save feedback.
- **Cleaner sound replacements.** Lone punctuation left after an Audio Stim no longer becomes a spoken fragment or a punctuation-only clip. Normal sentence punctuation stays intact.

## Update

Use the download icon beside the version number, or download
**YapLoq-Windows-x64-update.zip** and extract the complete folder.

Windows 10/11, 64-bit. Keep `_internal` beside `YapLoq.exe`. No Python installation
is required. The app is unsigned, so Windows may show a SmartScreen warning.
