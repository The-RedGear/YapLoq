# YapLoq 0.6.1

A small update to make queue actions, editing and saving more reliable.

- **One queue-added trigger per message.** Splitting speech between voices or
  sentences no longer runs the queue-added action for every clip.
- **Action names update as you type.** The left-hand list reflects the name
  you're editing. New actions start with an empty name field.
- **Clearer placeholders.** Hint text disappears when you focus a field and
  returns if you leave it empty.
- **Save and exit works reliably.** The app closes after a successful save.
  If saving fails, the prompt stays open and shows the reason.
- **Reliable live settings.** Rapid saves on Windows are detected without
  losing your unsaved changes.

## Update

Use the download icon beside the version number in YapLoq, or download
**YapLoq-Windows-x64-update.zip** and extract the complete folder.

Windows 10/11, 64-bit. Keep `_internal` beside `YapLoq.exe`. No Python installation
is required. This build is unsigned, so Windows may show a SmartScreen warning.
